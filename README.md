# Tendium Scraper

Playwright-based scraper for Tendium's awarded-contracts view, plus a local
Flask dashboard to run it, review results, and track upcoming contract
renewals.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## First run (manual login)

Either run the scraper directly:

```bash
.venv/bin/python tendium_scraper.py
```

...or start the dashboard and click "Run scraper now":

```bash
.venv/bin/python manage.py
# open http://127.0.0.1:5151
```

On the first run (no saved session yet), a visible Chromium window opens.
Log into Tendium there, then either press Enter in the terminal or click
"I've logged in" in the dashboard. The session is saved to `tendium_session/`
(gitignored) so future runs skip the login step.

### Optional: automatic login

If the browser window doesn't respond to clicks (a known issue with some
window-manager setups), save your Tendium email/password on the
**Inställningar** page instead. They're stored locally in `credentials.json`
(gitignored, `chmod 600`) and used only to auto-fill Tendium's own login
form — the scraper never sends them anywhere else.

## Configuration

All settings (target URL, headless mode, timeouts, renewal alert window,
etc.) live in `config.json` (gitignored, created automatically on first run
with sane defaults — see `scraper_config.py`). Edit it directly or through
the dashboard's Inställningar page.

## Scheduling

See [CRON_GUIDE.md](CRON_GUIDE.md) for running this on a daily schedule via
cron (Mac/Linux) or Task Scheduler (Windows).

## Project layout

- `tendium_scraper.py` — the Playwright scraper
- `manage.py` — Flask dashboard (`/` overview, `/settings`)
- `scraper_config.py` / `credentials.py` — shared config and login storage
- `templates/` — dashboard HTML
- `tendium_tenders.csv` — scraped output (gitignored, regenerated by runs)
- `debug/` — HTML/screenshot snapshots for troubleshooting selectors (gitignored)
